# Getting Started

This section is for durable, topic-based learning notes.

## Suggested note structure

A useful note usually includes:

1. **Summary** — the idea in a few sentences.
2. **Key concepts** — terminology and important details.
3. **Examples** — code, diagrams, or worked problems.
4. **Open questions** — topics to revisit.
5. **References** — links to original sources.

## Example code

```python title="hello_ai.py"
def ask(question: str) -> str:
    return f"Learning question: {question}"


print(ask("How do transformers use attention?"))
```
